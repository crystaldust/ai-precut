## 1. 抖音：当前推荐机制的核心逻辑

### 1.1 官方已经明说的算法骨架（2025-04-15 开放日）

2025 年 4 月 15 日，抖音在北京办"安全与信任中心开放日"，首次系统性公开推荐算法原理。核心口径（🟢，多源一致）：

> 抖音推荐算法的核心逻辑可以简化为"推荐优先级公式"：
> **综合预测用户行为概率 × 行为价值权重 = 视频推荐优先级**

配套的官方表述（🟢）：

- 算法流程是**召回 → 过滤 → 排序**，重点是学习用户行为（点击、浏览、喜欢、转发、收藏等）；
- "抖音算法已**几乎不依赖**对内容和用户打标签，而是通过神经网络计算，预估用户行为，计算用户观看这条内容获得的**价值总和**"；
- 使用 Wide&Deep 模型、双塔召回模型；已实现"**分钟级**实时反馈更新"；
- 多目标体系是**被迫进化**的：早期只看完播率等少数目标，但"平台上有了越来越多的**优质中长视频**，完播率等少数目标难以满足需求"；
- 新增/增强的目标（这是全文最关键的一段，🟢）：
  1. **收藏率**（帮助知识类内容找到有需求的人）；
  2. 组合目标：**"收藏+复访"**、**"关注+追更"**、**"打开+搜索"**——用来"预估用户**长期**行为"；
  3. **探索类指标**（帮用户发现自己都还没发现的潜在需求，破信息茧房）；
  4. **原创性目标**（鼓励优质、新颖、独特价值的内容）。
- 治理侧：所有内容都会过评估，"**流量越高的内容经过评估的次数越多，标准也越严格**"；被举报、评论区集中质疑、流量激增都可能触发"人工+机器"复核；"一旦内容被处置，基本都会**立即停止**进一步的推荐和分发"。

**来源**：鞭牛士 2025-04-16《抖音公开算法原理：通过神经网络计算预估用户行为，几乎不依赖打标签》；新榜 2025-04-15；新华网 2025-04-17。

### 1.2 行为权重差异：官方只给方向，不给数值

这是最容易被编造的部分。必须先说清楚：

> 🔴 **抖音从未公开过任何行为的权重数值**（没有"完播 30%、点赞 10%"这种表）。任何给出具体百分比的"算法拆解"都不可信。

官方能给到的**方向性信息**只有这些（🟢 原文 + 🟡 推断）：

| 行为 | 官方定位 | 相对地位（据官方口径推断） |
|---|---|---|
| 完播 / 播放时长 | 早期核心目标，现在"等少数目标难以满足需求" | **基础门槛**，不再是唯一决胜项 |
| 收藏 | 2025 年被单独"纳入多目标" | **上升最快**，且是"长期需求"的代理指标 |
| 收藏 + 复访 | 被明确列为"组合目标" | 高于单次收藏（衡量长尾价值） |
| 关注 + 追更 | 被明确列为"组合目标" | 高于单次关注（衡量账号黏性） |
| 打开 + 搜索 | 被明确列为"组合目标" | 新增权重方向，且与"探索类指标"联动 |
| 点赞 | 基础互动，未被单独强调 | 常规项 |
| 评论 | 基础互动；官方提到"评论区集中质疑"会触发复核 | 常规项，但**负向评论是风险信号** |
| 转发 | 基础互动 | 常规项 |
| 原创性 | 2025 年新增为**独立目标** | 影响"能不能拿到推荐"的资格线 |

🟠 **行业解读（非官方，需谨慎）**：多个代运营/行业媒体在 2025 年提出"收藏权重超过完播率与点赞"、"收藏成为第一核心指标"。**查不到任何官方文件支持"第一"这个说法**，只能理解为"收藏的相对权重显著上升"。做内容决策时，把它当"方向"而不是"排序"。

**对剪辑的含义（重要）**：
- 完播率仍是**入场券**（看不完就没有后续行为），但**只优化完播会把你推向"7 秒反转 + 无信息增量"的死胡同**；
- 真正被加权的是"看完之后的行为"——所以片子必须**留下一个可被收藏的东西**（清单、方法、观点、金句、信息密度），并在结构上**为"复看"设计**（前后呼应、二刷才懂的细节）。

### 1.3 "5 秒完播 / 完播率"权重是否下降？

**结论：方向性下降是事实，具体幅度未公开。**

- 🟢 官方原话是"完播率等少数目标难以满足需求"，并把收藏率、组合目标、探索指标、原创性列为新增目标。在"多目标加权"的框架里，**新增目标必然稀释旧目标的相对权重**——这是机制层面的推论，不是猜测。
- 🟢 官方同时强调"分钟级实时反馈"，意味着**前几秒的负反馈（划走）依然会立刻影响这条视频的后续分发**。所以"5 秒完播不重要了"是误读：**它从"决胜指标"变成了"止损指标"**。
- 🟠 行业观察（2025 年下半年多篇复盘）：单纯靠"前 3 秒强刺激 + 7 秒结尾"的短平快内容，播放量波动变大、长尾变差；而 3–10 分钟的深度内容出现"低完播、高播放"的案例（如知识类长视频靠收藏与复访起量）。**这些是个案，不构成统计结论。**

**给你的操作结论**：
> 前 3 秒仍然要"止损"，但**不要再为了 5 秒完播牺牲信息量**。判断标准从"5 秒留存率"改成"**5 秒留存 × 完播 × 收藏率 × 主页访问**"四个数一起看。

### 1.4 流量池递进：官方没有"阶梯表"

🔴 **抖音从未公开"初级流量池 200–500 播放、达标进 1000–5000"这类分档规则。** 这是行业长期流传的经验模型，被无数次转述后成了"常识"。

可以确认的官方机制（🟢）：
- 分发是**连续、实时**的（"分钟级实时反馈更新"），不是固定几档跳变；
- **流量越高，评估次数越多、标准越严**（多轮次审核叠加）；
- 内容被处置后**立即停止**推荐；
- 探索机制会让内容被推给"非核心兴趣人群"（多样性打散、随机推荐、社交关系拓展、搜索联动），所以**同样的数据在不同人群包里表现会不一样**。

🟠 **从业者通行模型（仅作复盘框架，不要当阈值）**：

```
发布 → 初始小流量测试（粉丝 + 相似人群）
     → 看 5s/完播、互动率、负反馈（不感兴趣/举报）
     → 达标 → 扩到更大的人群包（同时叠加更严的审核）
     → 数据衰减 → 停止；若出现收藏/复访/搜索 → 可能二次激活
```

**可执行做法**：不要盯"有没有进下一个池"，盯**"这条视频的流量来源结构"**——推荐页占比、搜索占比、主页占比、关注页占比。搜索/主页占比上升，说明长尾在启动（这是 2025 年机制真正奖励的东西）。

### 1.5 账号标签与冷启动：官方说"几乎不依赖标签"，怎么理解

🟢 官方明确："算法已几乎不依赖对内容和用户打标签，而是通过神经网络计算，预估用户行为。"

这句话常被误读成"标签没用"。更准确的工程解释（🟡，结合官方对 Wide&Deep / 双塔召回的说明）：

- 标签（创作者自填的话题、类目）仍然进入召回，但**不再是主要匹配手段**；
- 真正起作用的是**内容向量 + 用户行为向量**的匹配：系统看的是"这条内容被哪类人看完/收藏/搜索"，而不是"你打了什么标签"；
- 因此**冷启动的本质是"让系统快速识别你的内容该给谁看"**，而不是"把标签打全"。

**对剪辑/发布的具体含义**：
1. **前 3–5 条要"人群可识别"**：同一账号前几条尽量收敛在同一人群、同一叙事风格，别今天悬疑解说、明天情感口播——不是为了"打标签"，是为了让**早期行为样本不打架**。
2. **话题要"内容相关"**：快手 2025 光合大会把"挂载更全面且和视频内容相关的话题"列为四大流量密码之一（🟢）；抖音侧同理，话题是召回入口，不是装饰。
3. **标题/口播里要埋"搜索词"**：官方把"打开+搜索"列为组合目标，搜索是**主动意图**，权重质量高于被动推荐。
4. **别迷信"养号"**：官方口径下没有"养号权重"这回事；🟠 从业者说的"养号"本质是"让账号行为看起来像正常用户"，属于风控层面，不是流量层面。

## 2. 抖音：能直接映射到剪辑动作的规则

### 2.1 前 3 秒钩子：机制上为什么重要、重要到什么程度

**机制依据（🟢 + 🟡）**：
- 单列全屏、上划成本≈0，前几秒是**唯一的"止损窗口"**；
- "分钟级实时反馈"意味着早期划走会立刻反馈到分发；
- 但 2025 年后完播率只是多目标之一 → **前 3 秒决定"有没有后面"，不决定"能不能爆"**。

**可执行拆解（🟠 经验 + 🟡 结构逻辑）**：

| 时间段 | 必须发生的事 | 禁止 |
|---|---|---|
| 0–0.5s | 画面已经有"信息事件"：人脸/动作/冲突台词/反常识画面/大字标题 | 黑场、片头 LOGO、BGM 淡入、空镜起手 |
| 0.5–1.5s | 用一句话（≤15 字）抛出**冲突或身份**："我在这行干了 8 年，第一次见……" | 自我介绍、寒暄、"大家好" |
| 1.5–3s | 给出**利益承诺或悬念**："三分钟讲清楚，为什么它能爆" | 铺垫背景、交代前情 |
| 3–5s | 兑现第一个信息点（不能只挖坑不填） | 继续拖钩子 |

> **反直觉但重要**：钩子不是"更吵更快"，是"**信息不对称**"。观众留下是因为"我还不知道答案"，不是因为"画面很炸"。

### 2.2 黄金结构：钩子—冲突—反转—共鸣—引导

这是行业模板（🟠），不是官方规则。但可以按抖音 2025 的目标体系重排优先级：

```
0–3s     钩子        → 目标：止损（5s 留存）
3–15s    冲突/悬念    → 目标：完播（中段留存）
15–35s   推进/反转    → 目标：完播 + 评论（情绪峰值）
35–50s   共鸣/价值    → 目标：收藏（"这条有用"）+ 转发（"这说的是我"）
50–60s   引导         → 目标：关注/追更/搜索（组合目标）
```

**关键改动（相对 2023 年的老模板）**：
- 老模板把"引导"放最后 3 秒，只求点赞；
- 新模板要求**在 35–50 秒处有一次"值得收藏"的交付**（清单/方法/结论），否则收藏率起不来；
- **"追更"要具体**：不是"关注我"，而是"下条讲 XX，关注不迷路"——给的是**下一次打开的的理由**，对应官方"关注+追更"组合目标。

### 2.3 视频时长与完播的权衡

🟢 官方给了最硬的依据："平台上有了越来越多的优质中长视频，完播率等少数目标难以满足需求。"——**平台自己在为"长内容低完播"做算法兜底**。

**时长决策表（🟠 经验值，需按赛道校准）**：

| 时长 | 适合的内容 | 完播压力 | 收藏/复访潜力 | 建议 |
|---|---|---|---|---|
| 7–15s | 强冲突、猎奇、情绪爆点、纯卡点 | 极高 | 极低 | 只做"引流钩子"，不做主力 |
| 15–30s | 单点反转、剧情段子、口播金句 | 高 | 低 | 新号起量用，别长期只做这个 |
| 30–60s | 剧情完整段落、口播一个观点 | 中 | 中 | **主力档**，结构最容易做完整 |
| 60–90s | 口播两个层次、影视单点解说 | 中低 | 中高 | 需要"信息密度"支撑 |
| 90s–3min | 深度解说、案例拆解、系列单集 | 低 | 高 | 靠收藏+复访+搜索吃长尾 |
| 3min+ | 深度知识、完整拉片 | 极低 | 极高 | 只适合已有粉丝/强选题，新号慎用 |

**"完播率陷阱"（🟠，但有官方机制支撑）**：
- 为了完播把内容压到 10 秒 → 收藏、关注、搜索全部起不来 → **只拿到一次性流量，拿不到账号权重**；
- 平台 2025 年新增"原创性目标"和"低质重复"治理 → 大量同质化短内容会被判"低质工业化内容"（官方对"恶意营销号"的定义原文就包含"工业化生产和批量发布同质化内容"）；
- **正确做法**：用 15–30s 做"钩子内容"拉新，用 60s–3min 做"资产内容"沉淀收藏与复访，两条线并行。

### 2.4 字幕 / 花字 / 音效 / BGM 对留存的影响

**必须诚实**：🔴 **没有找到抖音官方发布的"字幕字号/每行字数/BGM 音量"规范**，也没有可信的公开 A/B 数据证明"加字幕能提升 X% 完播"。以下是**机制推导 + 行业通行做法**，请当起点参数。

| 元素 | 机制上的作用 | 建议做法 |
|---|---|---|
| 字幕 | 静音场景下的"第二轨道"；也是**搜索/ASR 识别的文本来源** | 全程硬字幕；关键词加粗变色；口播与字幕**逐字对齐**（错字/延迟会直接掉留存） |
| 花字 | 制造"视觉节拍"，替代运镜 | 每 5–8 秒一次花字弹入，位置避开人脸与底部 UI |
| 音效 | 转场/反转的"听觉标点" | whoosh/riser/ding，单次 ≤0.3s，不要每个切点都加 |
| BGM | 情绪底色 + 节奏骨架 | 人声优先；BGM 比人声低 12–18dB；**不要用 BGM 盖住口播** |
| 卡点 | 用音乐重音标记结构转折 | 重音落在"反转/金句/转场"的第一帧，不是随便踩 |

> 一个容易被忽略的点：**字幕是给算法看的**。抖音的搜索、内容理解都依赖文本，口播里说清楚的词，字幕里也要出现——这直接服务"打开+搜索"这个官方组合目标。

### 2.5 封面与标题（3:4 的问题）

- 🟠 **抖音主页/推荐场景的封面，行业通用规格是 3:4 竖版（1080×1440）**；视频本身是 9:16。3:4 的作用是**主页三列网格不变形、信息更聚焦**。
- 🔴 **没有找到抖音官方强制"必须 3:4"的公告**；这是产品显示逻辑 + 行业惯例，不是硬规则。
- 🟡 平台都治理"**封面党、标题党**"：快手社区规范有明确条款；抖音"恶意营销号"规范列了"不当蹭热博取关注""诱骗强迫互动不当获利"，逻辑一致，只是没有逐字用"标题党"这个词。所以封面的底线是：**封面承诺的内容，视频里必须真的有**。

**封面/标题写法（🟠）**：

| 项 | 建议 |
|---|---|
| 封面构图 | 主体居中偏上，人脸占画面 1/3 以上；底部 20% 留空（避免被时长/文案压住） |
| 封面文字 | 6–10 字，一行；字高 ≥ 封面高度 8%；白字黑边或黄字黑边 |
| 封面信息 | 只讲**一个**冲突或一个结果，不要塞三个卖点 |
| 标题长度 | 12–22 字；前 6 字必须含冲突词/关键词（信息流只露出前几个字） |
| 标题结构 | "身份 + 反常识 + 结果" 或 "问题 + 代价"；带 1 个搜索词 |
| 禁忌 | 夸张承诺、伪造身份、与内容不符（官方治理项） |

### 2.6 发布时间

🔴 **没有任何官方"最佳发布时间"数据。** 所有"早 7 点、晚 8 点"的说法都是经验。

**可执行替代方案（比记时段更有效）**：
1. 固定 **2–3 个时段**（例如 12:00 / 18:30 / 21:00），每个时段各发 3 条，连续两周；
2. 只看三个指标：**发布后 2 小时的播放完成度、24 小时的收藏率、7 天的搜索/主页进入占比**；
3. 选"7 天长尾最好"的时段，而不是"2 小时爆发最高"的时段——这与 2025 年后的权重方向一致。

🟠 经验规律（仅供参考）：剧情/影视解说偏 18:00–23:00；知识口播偏 7:00–9:00 与 12:00–14:00；周末上午适合家庭/情感类。

### 2.7 DOU+ 与自然流的关系

🔴 **没有找到抖音官方关于"DOU+ 是否影响自然推荐"的算法说明。** 任何"投了 DOU+ 就会压制自然流/就会带动自然流"的断言都缺一手依据。

可以确认的（🟢/🟡）：
- DOU+ 是**付费加热工具**，买的是曝光，不改变内容评估标准；
- 抖音官方强调"流量越高的内容评估越严格"——**投流放大的内容同样在治理范围内**；
- 🟠 行业共识：DOU+ 是"放大器"不是"起号器"。内容自然数据不达标时投流，只会把"低完播"放大给更多人，并可能把账号人群标签带偏。

**实操建议（🟠）**：
1. 先用自然流跑 24–48 小时，确认**完播 + 收藏率**在账号正常区间，再考虑小额加热；
2. 加热目标选"**粉丝/主页访问**"而不是纯"播放量"，与"关注+追更"目标对齐；
3. 单条加热不超过自然播放的 30–50%，避免数据失真、误判选题。

### 2.8 中长视频的长尾

🟢 官方数据（2025 创作者大会）：优质内容播放量同比 **+160%**、播放时长 **+220%**，平均播放时长是普通内容的 **17 倍**。

🟠 行业案例：知识类超长视频（如 450 分钟讲《红楼梦》）在完播率极低的情况下获得千万级点赞与上亿次播放——这类案例说明**平台确实为"低完播高价值"内容留了通道**，但它依赖极强的选题独占性，**不能作为普通剪辑师的默认策略**。

**对剪辑的启示**：
- 中长视频不要"拉长"，要"**加密**"：每 30 秒必须有一个可独立成立的信息点；
- 为"二刷"设计：开头埋的细节，中段回收；结尾留一个"下条再看"的钩子；
- 结构上做**章节感**（小标题卡/章节字幕），让观众知道"还有多久"，降低中途放弃率。

## 3. 快手：与抖音的机制差异

### 3.1 单列 vs 双列：最底层的产品差异

🟡 经典分析（乱翻书/36氪，机制层面仍成立）：

| | 抖音（单列全屏） | 快手（双列点选为主） |
|---|---|---|
| 用户动作 | 上划，**不能选择不看** | 先看封面，**点击**才进入 |
| 多出的指标 | — | **封面→内容 的 CTR**（极强的主观意图信号） |
| 数据含义 | 停留时长等行为"表意弱" | 点击是"强表意"，算法更快抓到真实兴趣 |
| 容错率 | 低（必须聚焦头部/高完播） | 高（可容纳更多元、更长尾的内容） |
| 核心优化指标 | 人均 VV > 投稿率 > 人均关注数 | **投稿率 > 人均 VV > 人均关注数** |
| 产品属性 | 强媒体 | 强社区 |

> 注意：🟠 快手 App 后来加入了单列沉浸模式（可切换），双列不再是唯一容器。但"**点击意图 + 关注关系 + 私域**"这套底层逻辑没有变，上面的差异仍然成立。

**对剪辑的直接含义**：
- **快手的第一关是封面和标题**（决定点不点），抖音的第一关是前 3 秒（决定划不划）；
- 快手可以容忍"慢热"，因为用户是**主动选择**进来的，前 3 秒不需要像抖音那样"爆炸"；
- 但快手对"**封面承诺不兑现**"更敏感——点进来发现货不对板，跳出+负反馈的伤害更大。

### 3.2 私域与"老铁"关系链权重

🟢 快手 2025 光合大会（2025-08-29）官方数据：

- 短视频与直播**双优**的作者，获取流量的效率比单一形式作者高 **4–10 倍**；
- 创作者**开播期间**，其短视频可获得 **超过 50%** 的流量增量；
- 私域高价值创作者在公域获得的曝光量环比 **+10.2%**，带动新增关注 **+7.2%**；
- 电商场景：公域流量占比约 **70%**，但**私域转化率是公域的 4 倍以上**；"短直双开"带来的 GMV 是单一短视频的 **5 倍**；
- 私域用户日均互动 **40 亿次**；2025 Q2 DAU **4.09 亿**，总使用时长同比 +7.5%。

🟢 快手技术副总裁李晗在光合大会给出的"**四大流量密码**"：
1. 提高**深度互动**行为；
2. **聚焦垂类**创作；
3. 保证作品的**基础质量**和持续优质产出；
4. 挂载**更全面且与视频内容相关**的话题。

**这意味着**：快手不是"内容分发型"平台，而是"**关系经营型**"平台。同一条视频，在快手要多做三件事：
1. **口播里叫得出人**（"老铁""家人们"是社区语言，不是土）；
2. **结尾导向直播/关注**（而不是只导点赞）；
3. **持续同一人设、同一垂类**（垂类是快手明确的流量密码）。

### 3.3 普惠 vs "流量向优"：2025 年的转向

🟢 历史口径：2019 年快手高级副总裁马宏彬公开表示，快手**引入基尼系数调节流量分配**，让流量向长尾内容倾斜、朝普惠方向发展。

🟡 2025 年口径（光合大会披露，经媒体报道）：大会提出"**流量向优**"——让"长期耕耘的好作者和好内容获得好流量"；官方数据称**优质内容获得的流量是其他内容的 24 倍，优质作者是 17 倍**；并披露"从冷启到推爆的作品生命周期机制"，让新作品**获得高曝光的机会增加 35%、获得万赞的机会提升 22%**，评判维度是**画质、互动率、稀缺度**。

**怎么理解这个转向**：
- 普惠没有消失（长尾仍有基础流量），但**"优质"成了乘数**；
- "优质"在快手是可操作的三个词：**画质、互动率、稀缺度**——这比抖音的"多目标"更直白，也更容易落到剪辑上（见第 6 节快手特化参数）。

### 3.4 内容偏好差异

🟠 行业共识 + 🟢 官方话语（"真实""老铁""信任"）交叉验证：

| 维度 | 抖音 | 快手 |
|---|---|---|
| 审美 | 精致、节奏快、强包装 | 真实、有生活毛边、弱包装 |
| 叙事 | 高概念、强钩子、反转 | 人物、关系、日常、陪伴 |
| 口播 | 信息密度高、观点锋利 | 像跟人聊天、有口音也没关系 |
| 信任来源 | 专业感/权威感 | **长期出镜 + 一致性 + 互动** |
| 影视剪辑 | 解说/混剪/高能片段 | 解说 + 老片/乡土/年代剧 + 直播陪看 |

### 3.5 涨粉与变现路径

🟢 快手官方（光合大会）：
- 一年内在快手获得收入的创作者 **2600 万**，月收入过千的创作者同比 **+近 12%**；
- 万粉以上创作者投稿量同比 **+100%**；
- 方向：短直一体、公私域联动、短剧/小游戏分账、磁力聚星（商单）、快手电商。

🟠 影视解说类在快手的典型路径：
```
短视频解说（公域拉新） → 引导关注（私域沉淀） → 直播陪看/连麦（关系加深） → 带货/星图/分账
```
**关键差异**：抖音的影视解说更容易"一条爆款涨粉、然后断更掉粉"；快手的解说是"**人 > 片**"，观众追的是"你这个人的讲解"，所以**出镜/声音人设**比抖音更重要。

### 3.6 审核与限流红线（快手）

🟢 《快手社区管理规范》（kuaishou.cn/norm，持续更新）明确的处置方式：
- 内容处理：禁止被评论、**减少推荐**、删除；
- 账号处理：禁言、禁被关注、**减少推荐**、冻结；
- 直播处理：中止播放、限制权限、冻结。

🟢 与影视剪辑直接相关的条款：
- "未经授权，**盗用、转载、搬运**他人作品，发布与他人创意高度相似、疑似抄袭的内容"；
- "刻意使用夸张、耸动标题，或者**展示内容与标题不符的封面党、标题党**内容"；
- "恶意制造噱头博取关注或发布**诱导欺骗点击、骗赞骗双击**的内容"；
- 数据作弊（刷播放/点赞/粉丝）。

🟡 快手对"简单加工"的定性（媒体引述快手社区内容规则中心口径，原文未直接检索到）：
> 对存在版权风险的内容**仅进行简单加工**，例如**添加字幕、更换背景或调整画幅**，而未在原作基础上融入个人观点与原创性表达的，属于**违规的搬运行为**。

——这条几乎就是给影视剪辑师的"判决书"：**加字幕/改画幅/换背景 ≠ 原创**。

## 5. 两平台通用：违规 / 限流红线

### 5.1 搬运与非原创的官方判定标准

🟢 抖音《关于"恶意营销号"的治理规范》（2025-04-28）对"搬运"的定义原文：

> "未经授权抄袭他人创作的作品，或**简单裁剪拼接、未经创作加工直接使用**，或**掐头去尾、替换文案、伪装成'原创'**内容发布。"

🟢 抖音短剧版权中心《关于内容原创度建议的公告》（2026-03-13）进一步细化，以下行为会被治理：
1. 同一部短剧/漫剧在**多个账号重复发布**；
2. **相同或相似素材**在多个账号重复发布；
3. 直接搬运或抄袭；**素材画面中带有他人水印号，或用马赛克等方式遮挡他人水印**；转载他人原创作品（**即使获得口头/文字授权**）；
4. **将外站非本人素材直接发布，或简单加工（加特效、转场、配乐、文字、一句话解说）后发布**。

**注意第 3、4 条的杀伤力**：
- "有授权"不代表平台认可——平台要的是**版权链证明**，不是聊天记录；
- "加特效/转场/配乐/字幕/一句话解说"被明确列为**简单加工**，不构成原创。

### 5.2 影视二创的版权边界（法律层面）

🟢 关键判例：江苏省靖江市人民法院审理的《人间世》案（《人民法院报》2025-05-08 报道，判决已生效）：

- 被告在抖音发布《人间世》21 集剪选取集，粉丝 200 多万，单条播放近 30 万；
- 被告抗辩"解说类、适当引用、平台有二创激励计划"；
- 法院认定：**画面多为原片剪切，解说多为剧情浓缩和核心看点，部分解说与旁白基本一致，"公众连续点击观看便可基本获得案涉作品的大致内容"，与原始作品高度相似甚至可高度替代，不构成合理使用**；
- 判赔 **5.5 万元**（含合理费用）。

**从判决里能提炼出的"安全线"（🟡 法律推理，不是官方规则）**：

| 做法 | 风险 | 说明 |
|---|---|---|
| 完整搬运整集/整段 | 极高 | 直接侵权 |
| 剪成"选集/合集"，观众不看原片也能看完剧情 | **极高** | 本案核心认定点："可高度替代" |
| 解说但画面几乎全是原片、解说=剧情复述 | 高 | 同上 |
| 有独立观点/信息增量，画面只做必要引用 | 中低 | 需控制引用时长与连续性 |
| 出镜评论、拉片分析、对比研究、资料补充 | 较低 | "转换性使用"更强，但仍需授权或合理引用 |

🟢 补充判例：广东省珠海市中级人民法院（《平安浙江网》2025-09-29 以案说法）认定，用户对影视剧"讲解视频"系对剧情片段的选取剪辑，**公众通过观看该短视频即可获得原作品大致内容**，不符合"为介绍、评论某一作品或说明某一问题"的使用目的，**使用程度明显超出合理范围**，不构成合理使用；平台因上传侵权短视频被判赔 1.5 万元。裁判要旨与《人间世》案一致：**判断标准是"是否形成实质性替代"，不是"剪了多少刀"。**

🟡 另一个背景：2022 年爱奇艺、优酷、腾讯视频、芒果 TV 陆续与抖音达成影视二创授权合作，**授权的前提是"不得简单拆条，必须实质性二次加工"**（解说、观点杂谈、创意混剪等）。快手侧授权范围明显更窄（仅与乐视等部分内容合作），这也是快手影视二创侵权判赔频发的原因之一（钛媒体报道，2025-08-29：快手因版权纠纷累计判赔约 1.57 亿元）。

> **一句话结论**：**"二创"的法律护城河不是"改了多少"，而是"提供了多少原作没有的东西"。** 剪辑手法（变速、镜像、滤镜、画中画）本身不产生原创性。

### 5.3 水印与字幕擦除的界限

🔴 **没有找到抖音/快手针对"字幕擦除"的单独公开条款**。但可以从两条既有规则推导出边界（🟡）：

| 操作 | 判定 | 依据 |
|---|---|---|
| 保留原片水印/台标 | 通常构成"来源可识别"，**仍是侵权**（不能因为没去水印就安全） | 著作权法基本逻辑 |
| 用马赛克/裁剪/模糊**遮挡他人水印** | **明确违规** | 抖音短剧公告（2026-03-13）原文 |
| 去除平台水印后搬运 | 违规（搬运+去除权利管理信息） | 抖音恶意营销号规范 + 社区规则 |
| 擦除原片字幕，重新配自己的解说字幕 | **高风险**：若目的是掩盖来源、冒充原创 → 非原创；若为二创需要，必须保留授权/署名，且不能"可替代原作" | 判例 + 平台原创度规则 |
| 擦除自己视频的字幕重制 | 无风险 | — |

**实操建议**：
- 不要用"去水印/去字幕"作为"去重"手段——平台和法院都不认；
- 需要引用时，**保留可识别的来源信息**（片名、出品方），并在画面/简介中署名；
- 真正的"去重"是**结构重写**：换叙事顺序、换主题、加观点、加资料、加出镜，而不是换皮。

### 5.4 AIGC 内容标注要求

🟢 法规：《人工智能生成合成内容标识办法》，国家网信办等四部门 **2025-03-14 发布，2025-09-01 施行**；配套强制性国标《网络安全技术 人工智能生成合成内容标识方法》同步实施。

核心要求（🟢）：
- **显式标识**：文本开头/结尾/适当位置标注"AI生成"；音频加语音提示或节奏提示；图片/视频在适当位置加显著提示；
- **隐式标识**：文件元数据中嵌入 AIGC 属性、服务商、内容编号等；
- **任何人不得恶意删除、篡改、伪造、隐匿标识**，不得为他人提供此类工具或服务；
- 用户主动要求无显式标识内容时，平台可在协议约定+留存日志的前提下提供，但**用户再发布时必须自行声明并添加标识**。

平台落地（🟢，2025-09-01 前后公告）：
- **抖音**：上线"AI 内容标识"与"AI 内容元数据标识读写"两项功能；未主动标识的，平台检测后加"疑似使用了 AI 生成技术，请谨慎甄别"；核验到元数据隐式标识的，加"作品含 AI 生成内容"；
- **快手**：对 AI 生成内容加"AI生成"显式标识 + 元数据隐式标识；对疑似 AI 内容在周边显著提示；禁止恶意删除/篡改/隐匿。

**对剪辑师的含义**：
- 用 AI 生成画面/配音/数字人 → **必须主动声明**，别等平台打"疑似"标签（疑似标签会显著影响信任与转化）；
- **AI 配音 + 真人素材**的混合内容，若 AI 部分实质性构成内容主体，应标注；
- 用 AI 做"去水印/换脸/擦除" → 可能同时触碰 AIGC 标识 + 侵权 + 深度合成三条线。

### 6.6 抖音版 vs 快手版：同一条片子的两套参数

| 项目 | 抖音版 | 快手版 |
|---|---|---|
| 前 3 秒 | 直接上冲突/反常识，**不留呼吸** | 先**交代人物/场景**（0–3s），第 3–5 秒再抛冲突 |
| 时长 | 30–60s 为主 | 60–120s 可接受（多 20–30%） |
| 口播语气 | 观点锋利、信息密度高 | 聊天感、称呼"老铁/家人们"，可以停顿 |
| 字幕 | 更快、更碎、关键词高亮 | 可以整句、字号略大（中老年用户多） |
| 封面 | 强冲突大字 | 人物+场景+一句人话（双列下要"可读"） |
| 结尾 | 关注+追更 / 搜索词 | **直播预告**（"今晚 8 点直播间聊"）+ 关注 |
| 发布 | 配合流量高峰 | **配合开播时间**（开播前 1–2 小时发） |
| 素材 | 高能片段、强反转 | 完整故事、人物弧光、老片/年代剧 |

### 6.7 参数一致性校验（避免"参数打架"）

以 **60 秒口播** 为例：
- 语速 5 字/秒 → 300 字；
- 字幕 12 字/行 → 25 行字幕 → 平均 2.4 秒/屏 ✔（在 1.2–2.5 秒区间内）；
- 每 5–8 秒一个信息点 → 8–12 个信息点 ✔；
- 每 10–15 秒一个小高潮 → 4–6 个 ✔；
- 单镜头 3–5 秒 → 12–20 个镜头 ✔。
**如果四个数对不上，说明结构有问题，先改结构再调参数。**

## 7. 7 天 / 30 天自测方案（替代"网传基准值"）

🔴 网上所有"完播率 30% 算合格""5 秒完播 60% 才推"的说法都**没有权威来源**。不同赛道、不同时长、不同粉丝量级差异巨大。**唯一可靠的做法是建立自己的基线。**

**第一周：建基线**
1. 用现有风格发 3 条，不改任何参数；
2. 记录：5s 留存、完播率、平均播放时长、点赞率、评论率、**收藏率**、**主页访问率**、**搜索进入占比**、粉丝净增；
3. 取中位数作为基线。

**第二至四周：单变量测试**（每次只改一项，3 条一组）

| 周 | 变量 | A 版 | B 版 | 看什么 |
|---|---|---|---|---|
| 2 | 首帧/钩子 | 现有 | 0s 上冲突画面 | 5s 留存 |
| 3 | 时长 | 60s | 30s（同素材重剪） | 完播 vs 收藏率 |
| 4 | CTA | 结尾关注 | 开头收藏 + 结尾追更 | 收藏率、主页访问 |

**判定标准（相对，不是绝对）**：
- 某项指标 ≥ 基线 **1.2 倍** → 保留；
- ≤ 基线 **0.8 倍** → 回滚；
- 7 天后仍在涨的版本 → 定为新基线（这对应"长尾"逻辑）。
