## 结论速览

| 待确认问题 | 结论 |
|---|---|
| 现有 Key 能否调用 | **能**。现有 MediaKit Key + 现有上传流程（申请上传地址时 `tool_name` 换成 `video-understand-router`）直接可用，不需要另开通、不需要新 Key |
| 输出格式 | **稳定**。9 / 9 次按提示词输出合法 JSON，事件首尾相接、覆盖整段，无空洞 |
| 画面理解质量 | **好**。能认出培训协议书、盖章、微信界面、电梯楼层、屏幕文字（「培训协议书」「23F」「营销中心」）；无人声段落描述完整 |
| 时间轴准确度 | Economy 档事件起点误差约 2–12 秒；**手动 2 fps 时约 0–2 秒**（抽帧核对：B 片段盖章实际从 130 s 开始，Economy 报 142 s，2 fps 报 130 s） |
| 档位 | 3–5 分钟片段上 Economy 和 Balanced 的 input tokens 完全相同（如 13,557），描述也几乎一致 —— 短片段上档位差别不大 |
| 每段 token / 耗时 | Economy：约 4,500 tokens / 分钟素材；手动 2 fps：约 4,500 / 分钟；手动 1 fps：约 8,500 / 分钟（反而更贵）。单段 40–100 秒完成，多段可并发 |
| 「可用性」判断 | **不可靠**：所有事件都给「可用」。画面可用性不能直接用模型自评，要交给后续判定（DeepSeek + 规则） |
| 音轨 / 能否替代 ASR | 只开 `need_audio`、提示词只问画面时，输出里没有对白内容。**提示词明确要求逐句转写时，能输出带时间戳、说话人的逐句文字**（C 片段：46 句，953 字，现有转写同时段 898 字；同一句的起点与现有转写相差约 1 秒；约 1 万 tokens / 3 分钟）。有替代潜力，但未做严格的错字率和说话人准确度评估 |
| 智能语义切片 | **用处不大**。默认参数下 B、C 片段直接按 28 / 30 秒等分，A 片段只有第一刀像语义切点；按时长另计费。不作为画面片段的切点来源 |

## 关键观察

1. **画面能补上转写看不到的内容**。A 片段开头的话题被文字分析命名为「调整车内设备」，画面理解显示实际是在办公室准备拍摄、坐电梯下楼、走到室外 —— 文字分析单靠只言片语会猜错场景。
2. **时间精度主要取决于抽帧密度**。Economy 档智能抽帧（约 1 fps 的 30%），边界常落在整数秒附近且滞后；手动 `fps: 2` 时边界与画面吻合（抽帧核对见上）。
3. **反常的 token 数**：手动 2 fps（19,153 input）比手动 1 fps（38,083 input）还少，推测服务端在帧数多时降低了单帧分辨率。说明 token 用量由服务端策略决定，产品里只能按结果中的 `token_usage` 记账，不能自己估算。
4. 返回结果中**没有模型名字段**，无法从结果确认实际使用的模型。

## 对 PRD 的建议

- **默认参数**：`manual_option: {fps: 2, need_audio: false}`，成本与 Economy 相当、时间更准。档位选项保留（省钱 / 均衡 / 精细），但「省钱」默认就用手动 2 fps；均衡 / 精细的差别需在更长片段上再验证。
- **切段**：单视频上限 1000 帧，2 fps 时每段最长约 8 分钟；取 **每段 5 分钟**（600 帧，留余量），60 分钟素材 12 段，同一任务最多 10 个视频，分 2 个任务并发提交。
- **代理素材**：5 fps、视频 300 kbps、单声道音频 32 kbps 足够（约 2.5 MB / 分钟，60 分钟约 150 MB）。分辨率沿用浏览小样（短边 ~300–540）。若后续用模型转写替代 ASR，音轨要保留；否则可以去掉音轨再省一点。
- **画面可用性**：提示词不再让模型直接给「可用 / 不可用」，改为输出客观事实（是否面向镜头、人是否在画面中、是否遮挡 / 晃动），由 DeepSeek 和规则判断。
- **画面片段切点**：用模型时间轴（2 fps）+ 本机镜头切点校正；**不采用语义切片**。
- **ASR 替代**：v1 仍保留 MediaKit 转写。另开一个小的后续验证：用 1–2 段完整素材对比错字率、说话人区分和切点误差，达标后再考虑「勾选画面理解时由模型同时转写」。

## 粗略成本

每小时素材约 27 万 tokens（画面，2 fps）。单价按模型而定，文档未给 mini 价格；以 pro 2.1 的 6 元 / 百万输入估算上限约 1.6 元 / 小时，实际 mini 更便宜。以控制台账单为准。

> **2026-10-30 第 3 阶段真账号验收修正**：按正式方案（5 分钟一段、手动 2 fps、无音轨）跑完整条 54 分钟素材，共 460,037 tokens（11 段，每段约 4.2 万），即约 8,400 tokens / 分钟、**每小时约 50 万 tokens**，是上面短片段估算的近两倍。剪辑台档位提示已按实测改为约 50 万。
