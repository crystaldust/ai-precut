# 剪辑台（图形界面）

> 界面是**六步项目向导**：① 新建 → ② 分析 → ③ 看素材 → ④ 定标准 → ⑤ 看结果 → ⑥ 导出（设计见 [界面流程 v2](界面流程-v2.md)）。
> ①–⑥ 和整个外壳都已完成（M13：①–④ 与外壳；M14：⑤ 看结果、⑥ 导出）。

给剪辑师用的界面：**双击启动 → 一步一步点 → 出片**。不用碰 JSON、不用记命令。

---

## 一、剪辑师怎么用

**启动**：双击 `启动剪辑台.command`（或打开 App），浏览器会自动打开（地址一般是 `http://127.0.0.1:8765`）。
关掉那个黑色终端窗口，就是退出。

**第一次打开**：先全屏告知外发数据流——音轨（16kHz 单声道）→ 火山引擎转写，转写文字 → DeepSeek 分析；
只在 ② 开启画面理解时，降质的低清代理视频（不是原始视频）→ 火山引擎理解画面。原始视频不出本机。告知内容变了会再确认一次
（加画面理解这一条时升到第 2 版）。点「我知道了，继续」后直接填两个 Key（只存本机钥匙串），都填好才进欢迎页。
之后在「更多 → 设置 · API Key」里改。

**界面外壳**

- 左边是**项目栏**：平时收成一条窄边（☰ + 项目首字），悬停或点 ☰ 浮出；点「固定」就一直展开（重启后也记得）。
  每个项目显示「名称 · 当前步骤」。
- 顶栏是**步骤条**：灰色 = 还没到（悬停会说先完成哪一步）；蓝色实底 = 当前；✓ = 已完成，可以回看；
  ⚠ 橙色 = 需要更新（比如改了偏好，要重新分析）。「更多」菜单里是项目设置、打开项目文件夹、清理缓存、
  设置 · API Key、快捷键、导出诊断包、关于。
- 有任务在跑时，顶栏出现**任务胶囊**（「正在分析 6/11 · 3 分钟」），点开看日志、取消。同一时间只跑一个任务；
  有任务时其它「开始」类按钮会置灰并说明原因。
- 底部是「← 上一步」「下一步：X →」。④ 的「下一步」就是闸门按钮「确认，生成分镜表」。

**六步**

1. **① 新建**：点「＋ 新建项目」，选素材文件，填项目名 / 片名 / 目标时长 / 风格预设；「剪辑偏好」（语气、观众、
   最多 3 句指定原话）可展开也可跳过。点「创建项目」后停在 ②，不会自动开始分析。以后想改偏好或片名：「更多 → 项目设置」
   （改偏好会让 ② 变 ⚠，要重新分析；只改片名不影响任何步骤）。
   **出片模式**：新建时选「简单（只用剪辑列表 · 推荐）」（新建默认）或「完整（AI 按标准选段）」，之后在「更多 → 项目设置」随时可改（没存过模式的旧项目按完整处理）。选简单时「剪辑偏好」标为「可选，影响 ③ 的 AI 分档」（语气、观众仍会影响 ② 的 AI 分档），「必须保留的原话」藏起来（只用剪辑列表，用不上）；选完整时和以前一样。简单模式没有 ④：③ 的下一步直接「去看结果」，步骤条上 ④ 置灰（「简单模式不需要定标准」）；进 ⑤ 时自动按剪辑列表重新出分镜表（只放剪辑列表里的片段，整段、按素材时间顺序，字幕和画面片段备注同完整模式；不按话题挑、不补时长、不挑开场和结尾，也不调用 AI 换算自定义想法）；分镜表手动改过的，会先问「覆盖 / 保留我的修改」。⑤ 顶栏只有「剪辑列表合计 · 镜头」，没有目标时长、AI 提示词和未采用清单；剪辑列表是空的会提示回 ③，不能生成预览片。目标时长、④ 的答案在简单模式里不起作用，改了也不会让 ⑤ 变「需要更新」；切换模式会让 ⑤ 变「出片模式改了 · 重新选段」。② 照样完整分析（包括生成 ④ 的决策问题），随时可切回完整模式。
2. **② 分析**：开始前先决定要不要开**画面理解（AI 多模态）**：可选、默认关闭，按项目保存；开启后选档位
   （省钱（默认）/ 均衡 / 精细），卡片上写明会把低清代理视频（不是原始视频）上传到火山引擎，素材涉及隐私时不要开启。
   分析中不能改（只显示一行「画面理解：已开启 · 省钱（默认） · 分析中不能修改；停止或完成后可以改，再重新运行」）；停止、失败或完成后可以改，
   分析完成后改了设置，② 变 ⚠「画面理解设置改过了」，点重新分析。
   点「开始分析」后是 11 项进度（读取素材 → 生成浏览小样 → 抽音轨 → 云端转写 → … → 初步选段），每项有状态和耗时；
   开了画面理解是 14 项，「画面检查」之后多「生成画面代理」（浏览小样切成 5 分钟一段、去掉声音的低清画面）、
   「云端画面理解」（逐段上传、产出画面时间轴；停止后再开始，做完的段不重传、不重新计费）和「整合画面与对白」
   （本机按时间把画面挂到每句话上，并找出没人说话、但画面有内容的时段；之后理解对白和分档时会参考画面：
   画面上能看到关键信息的待定段升为可用（寒暄、或只有「对」「嗯」这类一两个字的不升），背对镜头、人物出画、遮挡、晃动或画面与对白不符的可用段降为待定，
   说到关键信息的不降）。画面理解失败会停下说明是第几段、什么原因：可以重试，也可以关掉画面理解再重试（其它步骤照常）。
   2026-10-31 之前做过画面理解的项目，② 会显示需要更新；重新分析时只要浏览小样没变（没重新转码、项目没被复制过），
   就直接沿用已付费的画面结果、不重新上传，只在本机重新整合、再让 DeepSeek 补一次画面判断（约 3 万 token / 小时素材）。
   复制过的项目修改时间已变，认不回来，会重新上传计费。
   大约 10–15 分钟，可以关掉窗口，回来会接着跑。失败会说明失败的步骤和原因，点「重试（从这一步接着跑）」，
   已完成的步骤秒过；也可以「导出诊断包」。这台 Mac 编码器不可用时会提示并给诊断包入口。完成后自动进入 ③。
3. **③ 看素材**：上面是 AI 的理解（一句话摘要、关键信息、说话人、按档位上色的分布条）；下面是片段列表（按时间 /
   按话题，7 个筛选：全部 / 待定 / 可用 / 废片 / 剪辑列表 / 不可用 / 未用），右边是播放器和**剪辑列表**面板。
   挑段节奏：**↓ 换段 → 空格听 → S 放入剪辑列表**。A 标可用、D 标废片、X 标不可用（进片时彻底排除，包括手动分镜表
   里对应的镜头）、Z 撤销。剪辑列表里的片段 100% 进片（④ 排除了它的话题也照样进，⑤ 会提示）；合计超过目标时会提示建议改成多长，此时 AI 不再补镜头、成片会比目标长。
   没动过的片段（只是 ↓ 换过去）按 AI 的档位走：可用的进候选池，由 ⑤ 选段决定用不用；待定的到 ④「裁决待定」定，「剩下的按 AI 建议」时先不进片；废片不进片。
   快捷键可在「更多 → 快捷键」里自定义（与已有键冲突会被拒绝，可「恢复默认」；记在本机，所有项目通用）。
   标记之后 ⑤ 会变 ⚠「素材标记改过了」，不会自动重新选段。
   开了画面理解时：每句话下多一行「画面：…」和画面问题标签（晃动、背对镜头等），右边当前片段的「画面」折叠区（默认收起，展开后本次会话内记住）里是完整的画面描述、
   画面上的字、画面问题；没人说话、但画面有内容的时段作为**画面片段**（▣ 开头，主题列「画面片段」）按时间插在列表里，
   多一个「画面片段」筛选，按话题看时单独一组放最后。画面片段可以改档、标不可用、放进剪辑列表：放进去的整段进片，
   保留原声、没有字幕，分镜表备注「画面：<标题>」；不放进去就不会被 AI 选上，也不算进档位计数、话题时长和 ④ 的待定裁决。
   重新分析后画面片段编号可能变，改过的档按开始时间（前后 3 秒内）找回。
   每句对白下多一行灰色的**一句话总结**（≤20 字，② 分析里由 AI 单独写一轮，只描述这句说了什么）；总结是分析时写的，之后改过起止或文字的片段可能过时（可能过时，重新分析会只补改过的句子）；没有总结（旧项目、该轮失败）时照常只显示原文。
   列表里每句只显示前 60 个字，真被截断时末尾带「…」，完整原文在右边「当前段」里看（不再截断）；编辑起止弹窗里的原文也是全文，太长时在弹窗内滚动。
   **编辑起止**：AI 切的边界不准时，选中片段后点右边「编辑起止」或按 E，弹窗里拖时间轴的起点 / 终点手柄（范围是原片段前后各 60 秒），或直接输入开始 / 结束（m:ss.s，可超出手柄范围、不超过素材长度，至少 0.5 秒）。**播放头**：点时间轴任意位置（或拖动）把白色播放头移到那里，画面跟着定位，也可以在「播放头」输入框里写时间；空格播放 / 暂停，从播放头播到时间轴右端停（弹窗里任何位置的空格都管这个，不会触发列表的快捷键；弹窗里的按钮请用 Enter 触发，空格一律是播放 / 暂停）。拖手柄只预览手柄那一帧，松手画面回到播放头；手柄只有按住手柄本身才是拖手柄，按在时间轴其它位置都是移播放头；用鼠标拖手柄靠近播放头（8 像素内）会吸附上去，播放头变黄（键盘微调不吸附）。微调：点一下手柄或时间轴后按 ← →（动手柄或播放头），每次 0.1 秒，加 Shift 每次 1 秒；在输入框里按 ↑ ↓ 也一样；播放头不存盘，「恢复原始」也不动它；「▶ 播放选段」从开始播到结束并让播放头跟着走，「恢复原始」回到 AI 的边界。「保存」或「保存并加到剪辑列表」后，列表行显示「已调整」（悬停看原始起止），时长、分布条、剪辑列表都按新起止算；允许和别的片段重叠，Z 可撤销。进片和字幕都按新起止：剪短少字，延长到邻句会带上邻句的字。对白片段和画面片段都能改；重新分析后跟档位一样按原句找回。改完 ⑤ 会变 ⚠；如果 ⑤ 分镜表是手动改过的，要回 ④ 重新选段新起止才生效（保存时会提示）。
4. **④ 定标准**（闸门）：左边小目录显示三块的完成情况，三块都不强制：
   - **分析对不对**（可选）：摘要 + 话题 / 关键信息 / 说话人。话题可以改名（只改显示名）；展开话题可以改某段的档位。
   - **裁决待定**：一次一段，看原文、依据、听一下，**A 可用 / D 废片**，也可以「先跳过」。
     「剩下的按 AI 建议」= 剩下的待定先不进片，**不会替你标可用或废片**，之后仍可在 ③ 改。
   - **决策问题**：3–5 题，每个选项下一行「选了会怎样」；点选即自动保存；可以「重新出题」；兜底模板出的题会标明。
     每题最后有「自定义」（单选题选它 = 替换选项，多选题可与选项一起勾），题目之后还有「其他想法（自定义）」；
     写下的想法在确认后由 AI 换算成选段规则，回到 ④ 时输入框下显示「AI 理解为：…」，没能换算的说明原因。
   点底部「确认，生成分镜表」：保存答案并重新选段，完成后自动进入 ⑤。如果还有待定没裁完，会先问
   「还有 N 段待定，按 AI 建议处理？」，不会拦住你。改版前就出过片的旧项目，④ 顶部有一行提示，可以直接去 ⑤ ⑥。
5. **⑤ 看结果**（闸门 B）：
   - 顶栏：目标时长（点「改」就地改，确定后重新选段）· 当前总时长 · 镜头数 · 剪辑列表 N/M 进片 ✓；剪辑列表超过目标时长时
     变成警告条并直接给建议时长（此时 AI 不再补镜头）。剪辑列表里有片段属于 ④ 排除的话题时，页面顶部警告条会列出段数和话题，这些片段照样进片。
   - 顶栏右侧「查看 AI 提示词」：弹窗显示生成当前选段时发给 AI 的内容。选段本身是程序按规则计算的；只有 ④ 填了
     「自定义」想法，才会请 AI 换算成选段规则，此时显示系统提示词、用户提示词、AI 的原始回复、换算时间和每条想法的换算结果；
     没填就说明「本次选段没有调用 AI」。两种情况都列出最终选段规则（选项 + 自定义合并后）。
   - 左边是**分镜表**：字幕直接改（自动保存）、↑ ↓ 调顺序、✕ 删镜头、＋空镜、按时间排序；每镜有「为什么选它」，
     可展开看被删掉的替代句；选中一镜可以在播放器里设入点 / 出点。
   - 右上是**预览片**：点「生成预览片」（只在顶栏胶囊里显示进度）。**预览片不产生版本号**；分镜表改过后会提示
     「分镜表改过了 · 重新生成预览片」。
   - 右下是**未采用清单**：可用但没进片的段 + 原因（因时长 / 你删掉的 / 未勾选为必须记住的信息 / 剪辑列表里的片段要加回），
     每行「试听」「加回」（按时间插入，算一次手动修改）。
   - **手动修改与重新选段冲突**（改目标时长、④ 重新确认、③ 改标记后的横幅「重新选段」）：如果你手动改过分镜表，会先问
     「覆盖，用新的 AI 选段 / 保留我的修改 / 取消」；没有改动（或内容和 AI 选段一样）就不问。覆盖前原表自动备份在
     `work/shots_backups/`。「恢复为 AI 选段」（只在手动改过后出现）同样先确认、先备份。重新选段进行中分镜表是只读的。
   - 闸门按钮「看过了，去导出 →」：当前分镜表的预览片已生成才可点。
6. **⑥ 导出**：有历史版本，或当前分镜表的预览片已生成，就能进；一个版本都没有又没有预览片时是「未到」。
   - **本次导出**：显示「当前分镜表 N 镜 · 时长 · 预览片 时间」和这次会得到的版本号。
     「导出到 Mac 剪映」（剪映开着时先提示「剪映正在运行」，退出后点「我已关掉，继续」）、
     「生成 Windows 剪映包」（完成后出现「已生成 …_vN_Windows.zip」「在访达中显示」和一行用法：拷到 Windows 解压，
     双击 `INSTALL.bat`）。两个按钮都**晋升当前分镜表的预览片**为版本 vN，所以预览片不是最新的时候按钮置灰并说明
     「先在「⑤ 看结果」生成当前分镜表的预览片」。**同一张分镜表先导 Mac、再导 Windows 算同一个版本**；同一版再点
     「导出到 Mac 剪映」会变成「已在 Mac 剪映里：片名_vN」（剪映不允许同名草稿）。
   - 「打开剪映」只在检测到剪映专业版（`/Applications` 下、bundle id 校验过）时出现；没检测到就说明「装好后在剪映的本地草稿里找「片名_vN」」。
   - **历史版本**：每版一张卡片：版本号、「当前」标记、时间、镜头数、时长、预览片播放；Mac 剪映草稿名**只在真的导出到
     Mac 剪映的版本上显示**（改版前生成的旧版本标「改版前生成，未记录是否导入过」）；Windows 包的状态、「在访达中显示」。
     含已标为「不可用」片段的旧版本标红，**不能生成 / 定位它的 Windows 包**（预览片仍可看、可对比）。
   - **对比两版**：点「对比两版」，每张卡片出现勾选框，选满两个（选第三个会顶掉最早选的）→ 两个预览片并排「同时播放」，
     下面是镜头差异（新增 / 删除 / 改字幕「之前 → 之后」/ 改入出点 / 顺序变了）；缺留存分镜表的旧版本只并排播放并说明。
   - **回到这一版**：确认后把这一版的分镜表恢复成当前分镜表（原表自动备份、不删除任何版本；其中含不可用片段的镜头会被去掉并提示），
     然后回到 ⑤。改版前生成、没有留存分镜表的版本该按钮置灰。

> 每次**导出**才产生新版本（v1、v2、v3…），不会覆盖上一版；预览片不算版本。剪映里的草稿名是 `片名_v3`。

**常见操作对照**

| 想做的事 | 在哪点 |
|---|---|
| 改偏好 / 片名 / 预设 | 更多 → 项目设置 |
| 把一段放进片子 | ③ 选中后按 S（剪辑列表） |
| 这段绝对不要 / 涉及隐私 | ③ 选中后按 X（不可用） |
| 一次裁完待定 | ④ 裁决待定（A / D） |
| 换一句字幕 | ⑤ 分镜表 → 直接改那个输入框（自动保存） |
| 镜头长一点/短一点 | ⑤ 分镜表 → 选中 → 小播放器定位 → 设为入点/出点 |
| 删镜头 / 调顺序 / 加空镜 | ⑤ 分镜表 → ✕ / ↑ ↓ / ＋空镜 |
| 看一眼当前分镜表出来什么样 | ⑤ 生成预览片 |
| 导出一版 | ⑥ 导出到 Mac 剪映 / 生成 Windows 剪映包（版本号自动 +1） |
| 两版哪里不一样 / 退回某一版 | ⑥ 对比两版 / 回到这一版 |
| 出了问题要发给开发 | 更多 → 导出诊断包 |

## 二、开发者怎么维护

### 架构（三层，别搞混）

```
gui/static/index.html   界面（原生 JS，无框架无构建；一个页面、一个窗口，六步都在 #stage 里切换）
        ↓ fetch
gui/server.py           本地服务（127.0.0.1，只做转发和文件服务）；项目内容类接口在 gui/project_routes.py（③ 批量标记在 gui/browse_batch.py），
                        步骤状态 gui/wizard.py，⑤⑥ 的接口与数据 gui/result_routes.py / gui/result_payload.py，
                        剪映检测与打开 gui/jianying.py / gui/opener.py，分析进度 gui/analysis.py，界面偏好 gui/prefs.py，
                        任务子进程 gui/jobs.py，Key/告知 gui/settings.py
        ↓ subprocess
aicut.py                业务入口（和命令行完全同一套逻辑）
        ↓
pipeline/*.py           切、渲染、草稿生成、转写整理、废片检测
```

**原则：GUI 不实现业务逻辑。** 任何流程改动都改 `aicut.py`，GUI 只负责按钮和展示。这样命令行和界面永远一致。

### 加一个功能的标准路径

1. `aicut.py` 加子命令，本地跑通；
2. `gui/server.py` 加一个 `/api/xxx`，内部 `subprocess` 调它（异步任务用 `gui/jobs.py` 的 `start_job`，并在 `JOB_COMMANDS` 登记）；
3. 在对应步骤的 `gui/static/step-*.js` 加按钮 + 调接口（步骤状态由 `gui/wizard.py` 的 `derive()` 统一推导，前端不自己推）。

### 安全模型（单用户本机）

- 服务只监听 `127.0.0.1`，校验 `Host` / `Origin`，写接口要求 `application/json`。这挡住的是**别的网站**
  （浏览器里的跨站请求、DNS 重绑定）。
- **页面里没有任何凭证**（KI-88）。桌面壳 / 「启动剪辑台」打开的是一次性入口 `/?nonce=<随机串>`（5 分钟内有效、
  只能用一次，只存在服务进程内存里）；服务端兑换后下发会话 cookie `aicut_session_<端口>`
  （`HttpOnly; SameSite=Strict; Path=/`，每次启动随机、不落盘）并跳回去掉 nonce 的地址。之后页面、`/api/*`、
  `/media/*`（`<video>` 播放）都只认这个 cookie；`/static/*.js` 不含秘密，照常公开。M13 起只有一个窗口
  （没有子窗口）。没有有效 nonce / cookie 的页面请求只得到 403「请从剪辑台 App 打开」。
- 因此**同一台 Mac 上的其他用户或进程** `GET /` 拿不到任何凭证，也调不动接口。nonce 不出现在进程参数里：
  App 内由 pywebview 直接加载；浏览器模式经 `osascript` 的标准输入传给默认浏览器。
- 桌面壳用 `webview.start(private_mode=False)`；会话 cookie 本身不写盘，每次启动值都不同。
- **残余风险（KI-90）**：浏览器模式下 cookie 不按端口隔离。若本机另一用户在 `127.0.0.1` 的其他端口起服务并诱导
  剪辑师用**同一浏览器**访问，对方能收到这个 cookie。App（WKWebView 只加载剪辑台自己的页面）不受影响；多人
  共用的电脑请用 App，不要用浏览器模式。
- 浏览器模式：服务重启后旧标签页的请求会被拒（「页面已过期：请关掉这个页面，从剪辑台重新打开」）；
  不带 `--open` 启动时，终端会打印一条一次性入口链接。
- 页面 CSP 只允许同源脚本（`script-src 'self'`）；静态文件只发 `gui/static_files.py` 白名单里的。

### 已知限制

- 只支持 macOS（用到 `osascript` 选文件、剪映 Mac 版草稿路径）。

- 剪映 11.6 打开草稿后会自动加密工程，之后脚本不能再改写——所以永远出新版本，不改旧版。

```bash
uv run python aicut.py preview <项目>                       # 只生成当前分镜表的预览片（不产生版本）
uv run python aicut.py build <项目> --require-preview       # 晋升当前预览片为新版本并装进 Mac 剪映（预览片过期就停）
uv run python aicut.py build <项目> --require-preview --windows --no-draft   # 同一张表补 Windows 包，不新开版本
uv run python aicut.py select <项目> --manual=replace       # 重新选段，备份后覆盖手动分镜表（默认 keep）
```

服务端会把 `aicut.py` 的输出实时打到浏览器弹窗里，出问题就把那段日志发回来。
