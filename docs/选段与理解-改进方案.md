# 为什么"重要对话"被删了：理解与选段的改版方案

> 触发：剪辑师反馈"把一些重要的对话删掉了"
> 复盘对象：《九月一号》v3（54 分素材 → 2 分 56 秒）

---

## 一、先看数据：问题不在"删了几刀"，在"选择机制"

把成片和 140 段文稿逐段对齐后：

| 指标 | 数值 |
|---|---|
| 有对话的时长 | 47.7 分钟 |
| 进片的对话 | **3.4 分钟（7%）** |
| 被整体丢弃的段落 | **130 / 140 段** |
| 被丢弃、但含"钱/合同/退费/就业/年龄/补贴"的段落 | **24 段** |

被丢掉的东西里包括：退费条款细则、考证年龄限制（不满 16 周岁不能考）、高级证补贴与落户、实习工资四千、结业周期、宿舍与安全。

**这些恰恰是这类内容的信息骨架。** 剪辑师说"重要对话被删"，删的就是它们。

根因不是手抖，是三条机制问题：

1. **只用了文字这一路信息。** 声音（谁在强调、哪里抢话、哪里笑场）和画面（合同、印章、转账、表情）没有进入决策。
2. **选段是按"戏剧性"排序取前 N，没有"信息保底"。** 我挑的是金句和冲突，系统性地牺牲了条款和数字。
3. **没有确认闸门。** 剪辑师第一次看到我的取舍，是成片。她没有任何机会说"这句必须留"。

第四条是 brief 太宽——"日常记录"没有定义观众、目的、必须出现的内容。但这条只是放大了前三条。

## 二、调研：业界怎么解决"哪句话重要"

**1. EditIQ（2025，自动电影化剪辑）** —— [论文](https://ar5iv.labs.arxiv.org/html/2502.02172)

它做的是"固定机位 + 多机位虚拟切换"，但方法很值得抄：

- 用 **LLM 理解对话流**（谁在说什么、谈话怎么推进）；
- 用 **视觉显著性** 判断画面里什么是重点；
- 把"选哪个镜头"建模成 **带电影化约束的能量最小化/动态规划**，而不是逐条打分排序。

结论：**理解要双路（对话 + 画面），选段要带约束求解**。这和你说的 abc 综合是同一个方向。

**2. 多模态视频摘要综述（2025）** —— [IEEE](https://ieeexplore.ieee.org/abstract/document/11349049)

文本 / 音频 / 视觉三路特征融合是主流做法，单一模态在"重要性判断"上都有系统性偏差。

**3. 文本剪辑（Premiere / Descript）** —— [Adobe 文档](https://www.adobe.com/ph/en/learn/premiere-pro/web/text-based-editing-censor-effect)

把转写稿变成可编辑时间线：**删字就是删画面**。它的价值不在"自动"，在于**让取舍可见、可逆、可辩论**。

这提醒我：我们缺的不是更聪明的算法，是**把选段摊开给人看的那张表**。

**4. 商业高光工具（Opus Clip 等）**

它们是"挑高光"，目标是传播性（钩子、节奏、情绪峰值）。**这类评分不能直接拿来剪纪录片**——纪录片要"信息完整 + 表达有力"，只按传播性打分，必然把你说的"重要对话"当成"节奏拖沓"删掉。

这就是这次翻车的本质：**我用高光逻辑，剪了一条纪实片。**

## 三、改版方案：三路理解 + 覆盖式选段 + 两道闸门

### 3.1 三路理解，对齐到同一条时间轴

| 路 | 拿什么 | 怎么算 | 成本 |
|---|---|---|---|
| **声音** | 每句的能量（RMS）、语速（字/秒）、停顿、抢话重叠、笑声 | ffmpeg 逐段分析（本地） | 0 元，1 小时素材约 1–2 分钟 |
| **文字** | 说话人、话题分段、信息类型（承诺/数字/条款/异议/故事）、实体（钱/时间/人名）、金句候选、信息增量 | ASR + LLM 标注 | 云端 ASR（已有）+ LLM 分批 |
| **画面** | 镜头切分、景别、人脸数/朝向、手势、OCR（合同/手机屏）、道具（印章/转账/合同） | 抽帧 + OCR（mediakit video-ocr）/ 可选视频理解 | 按抽帧量计费，0.2 fps 粗扫 |

三路合并成一张 **内容单元表**：一行 = 一句话（2–15 秒），带三路特征。

### 3.2 双层打分：信息分保底，戏剧分加分

| 分数 | 看什么 | 作用 |
|---|---|---|
| **信息分**（保底） | 是否含数字/价格/期限/条件/承诺/资格限制；是否首次出现 | 决定"不能不提" |
| **戏剧分**（吸引力） | 反问、异议、笑声、强调、金句、情绪峰值 | 决定"怎么讲好看" |
| **画面分** | 有没有可看的画面（人脸/动作/道具） | 决定"配哪一镜" |

每条打三档：`必留`（brief 指定或信息关键）/ `可选` / `可删`。

### 3.3 覆盖式选段：先保话题，再挑句子

这是最关键的一处改动。现在做的是"按分数排序取前 N"，要改成：

```
1. 把对话切成 8–15 个话题（谁在谈什么）
2. brief 指定必须覆盖的话题（例：学费与退费、就业承诺、年龄限制、家属顾虑）
3. 每个必覆盖话题内选 1–3 句（信息分优先，戏剧分次之）
4. 剩余时长用可选段落填充，保证每 8–12 秒换镜
5. 约束检查：时长 / 话题覆盖 / 说话人平衡 / 不重复 / 字幕可读
```

一句话：**先把骨架立住，再往骨架上挂肉。** 而不是"挑最好看的 30 块肉"。

### 3.4 两道闸门（比算法更能救命）

**闸门 A · 内容清单**（切之前）

```
话题 1  学费与课程组合      6 段  建议保留 2 段
  □ 98    老师：三门总共九千八
  □ 99    妈妈：能不能便宜点          ← 她可以勾
话题 2  退费与就业承诺      9 段  建议保留 3 段
  ...
```

她勾完，我才开始切。**30 秒的操作，能省掉一整轮返工。**

**闸门 B · 选段表**（渲染前）

逐条列：时间码 / 台词 / 为什么选它 / 被删的替代句。她可以标"这句必须留"，我重排。

### 3.5 结构化 brief（替掉"日常记录"）

| 字段 | 例子 |
|---|---|
| 给谁看 | 想送孩子学手艺的家长 |
| 看完记住一句 | "学门手艺，比读七年书更实在" |
| 必须出现 | 学费金额、退费条款、就业承诺、年龄限制 |
| 绝不能出现 | 未成年人正脸、机构全称 |
| 情绪基调 | 冷静旁观，不煽情 |
| 时长/平台 | 3 分钟 / 快手、视频号 |
| 结构 | 时间顺叙（到场→看合同→交钱） |

## 四、落地改动

| 改动 | 文件 | 工作量 |
|---|---|---|
| 文稿增加声音特征（能量/语速/停顿/抢话） | 新增 `pipeline/understand_audio.py` | 0.5 天 |
| 文稿增加画面特征（镜头/OCR/道具） | 新增 `pipeline/understand_visual.py` | 1 天 |
| 话题分段 + 双层打分 + 覆盖选段 | 新增 `pipeline/plan_edit.py` | 1.5 天 |
| brief 模板（8 字段） | `presets/` 增加 `brief.schema.json` | 0.5 天 |
| GUI 加"内容清单"页（勾选必留） | `gui/static/index.html` + 1 个 API | 1 天 |
| 选段表导出（Markdown/CSV） | `plan_edit.py` 附带 | 0.5 天 |

剪映草稿、渲染、校验这些**都不用动**——它们只负责"按表施工"。

## 五、先做哪一步

按"能不能立刻止血"排序：

1. **闸门 A/B（半天）** —— 不改进算法，先让她看见取舍。这次的问题，一半靠这个就能避免。
2. **信息分 + 必留标记（1 天）** —— 含数字/承诺/条款/资格限制的句子，强制进候选。
3. **话题覆盖选择（1.5 天）** —— 从"挑金句"改成"立骨架"。
4. **三路特征（3 天，可并行）** —— 声音先做（免费、快），画面后做（要花钱）。

我建议 **1 + 2 一起做，48 小时内给她一版新的《九月一号》**，让她在同一条素材上对比。这比继续讨论算法更有说服力。

## 六、需要问剪辑师三个问题

这三个答案决定 brief 怎么写、权重怎么调：

1. **你希望保留的是"信息"还是"情绪"？** 比如"九千八"这句是必须留（信息），还是"妈妈读合同像看保险单"这种必须留（情绪）？
2. **这条片子给谁看？** 家长 / 同行 / 招生用 / 自己存档——不同观众，必须保留的话题完全不同。
3. **你觉得被删掉的哪几句最可惜？** 给我 2–3 句原话就行，我反推她的判断标准，比猜十次都准。
