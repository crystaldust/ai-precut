# 界面流程 v2：项目向导

> 2026-10-20 定。取代 [GUI.md](GUI.md)「剪辑师怎么用」里的旧流程（一排按钮 + 5 个标签页 + 3 个独立窗口）。
> 流程与闸门以 [PRD §4](PRD-AI粗剪工具.md#4-核心流程) 为准，术语以 [PRD §12](PRD-AI粗剪工具.md#12-附录术语) 为准。
> 对应登记：GL-26（向导）、GL-27（未采用清单）、KI-93..KI-98。设计稿：Pencil。

## 一、为什么改

旧界面的问题（2026-10-20 梳理）：

1. 没有步骤：选中项目后 9 个按钮全亮，未分析就能点「生成成片」「确认与提问」，失败了才知道不能用。
2. 同一动作多个入口且效果不同：「处理素材」3 处、「生成成片」3 处（只有一处带「只出预览」）。
3. 「告诉 AI 我要什么」散在 4 处（剪辑偏好窗口、浏览素材窗口、确认与提问窗口、文稿 ＋），互不联动：浏览页标了必留不会重新选段，生成时才被拒；确认页重选后主页不刷新。
4. 手动改过分镜表（哪怕一个字）后，答案和时长再也不影响分镜表，且无法恢复。
5. 名词混乱：「预览」tab 是分析用代理片，预览片在「版本」tab；「废片」既指画面技术问题又指内容档位；待定 / 待判断混用。
6. PRD 有、界面没有：未采用清单与一键加回（FR-8，P0）、不可用标记（FR-11）、版本对比与回退（FR-10）。

## 二、总体框架

```
┌──────┬───────────────────────────────────────────────────────────┐
│ 项目 │ 项目名 · 片名        ①新建 ✓ → ②分析 ✓ → ③看素材 → ④定标准 → ⑤看结果 → ⑥导出   [任务中…] [更多 ▾] │
│ 栏   ├───────────────────────────────────────────────────────────┤
│(可自 │                                                           │
│ 动隐 │                     当前步骤的页面                          │
│ 藏)  │                                                           │
│      ├───────────────────────────────────────────────────────────┤
│      │ 上一步                                         下一步：xxx → │
└──────┴───────────────────────────────────────────────────────────┘
```

**左侧项目栏**

- 展开时 240px：「＋ 新建项目」、项目列表（名称 + 当前步骤，如「⑤ 看结果」）。
- 自动隐藏：进入项目后收成 48px 窄条（只显示 ☰ 和当前项目首字）；鼠标移到窄条或点 ☰ 时浮出展开，移开自动收起。
- 展开面板上有 📌「固定」：固定后不再自动收起（记住在本机）。
- 没有项目时不隐藏，主区显示欢迎页（大按钮「新建项目」）。

**顶部步骤条**

| 状态 | 外观 | 能否点 |
|---|---|---|
| 未到 | 灰字 | 不能点（悬停提示「先完成 X」） |
| 当前 | 主色实底 | — |
| 已完成 | ✓ | 能回去看、能改 |
| 需要更新 | ⚠ 橙色 | 能点；上游改过，结果过期 |

- 往回改会让下游变成「需要更新」，不自动重跑；进入该步时页面顶部给一条横幅和按钮（如「素材标记改过了 · 重新选段」）。
- 后台任务一次一个。进行中时步骤条右侧显示任务胶囊（「正在分析 6/11 · 3 分钟」），点开看详情 / 取消；其它会启动任务的按钮置灰并提示「正在 X，完成后再试」。

**「更多」菜单（右上角）**：项目设置（片名、预设、剪辑偏好）、打开项目文件夹、清理缓存、设置 · API Key、快捷键、导出诊断包、关于 / 第三方许可。

**底部导航条**：「← 上一步」「下一步：X →」。下一步按钮只在本步可交接时可点；闸门步骤的下一步按钮就是闸门本身。

## 三、六个步骤

### ① 新建项目（弹窗，两段）

1. **素材与成片**：素材文件（选择）、项目名、片名、成片时长（分 + 秒，10 秒–60 分钟）、风格预设。
2. **剪辑偏好**（可展开，可跳过；FR-14）：
   - 更想保留：信息 / 情绪（单选，默认信息）
   - 片子给谁看（一行文字）
   - 必须保留的原话（多行，每行一句，最多 3 句）
3. 按钮：「创建并开始分析」「取消」。创建后直接进入 ② 并开始分析。

偏好之后在「更多 → 项目设置」里改；分析后改偏好 → ② 标「需要更新」（只重跑 AI 理解与之后的环节）。

### ② 分析（后台，可离开）

- 进度列表用人话，每项显示状态与耗时：读取素材 → 生成浏览小样 → 抽音轨 → 云端转写 → 声音分析 → 画面检查 → AI 理解对话 → 判定档位 → 写内容摘要 → 准备决策问题 → 初步选段。
- 顶部提示「分析大约 10–15 分钟，可以关掉窗口，回来接着跑」（FR-12）。
- 失败：哪一步失败 + 原因 +「重试（从这一步接着跑）」「导出诊断包」。
- 缺 Key / 未确认外发告知：在这页直接给「去填 Key」，不弹到别处。
- 完成后自动进入 ③。

### ③ 看素材（S2）

- **上方摘要卡**（FR-3）：一句话讲了什么；3–6 个关键信息（点时间码跳到该段）；说话人及时长。
- **分布条**：全片时间轴，按档位上色，点击跳转。
- **左：片段列表**（FR-4）
  - 视图：按时间 / 按话题（话题组头：可用 / 待定 / 废片数、可用时长）。
  - 筛选：全部 / 待定 / 可用 / 废片 / 剪辑列表 / 不可用 / 未用（不在当前分镜表里）。
  - 每行：时间码、档位标签、话题、原文、判定依据（人话）、画面提示小标签（过暗 / 抖动 / 虚焦 / 静止）、「＋ 剪辑列表」开关、⊘ 不可用。
- **右：播放器**：播原素材小样，从入点播到出点（前后各 0.3 秒）。
- **快速挑段（剪辑列表）**：点一下片段（或 ↑↓）把它设为当前段，按 **S** 放入 / 移出「剪辑列表」，空格照常播放。挑段节奏是「↓ 换段 → 空格听 → S 要」，手不离键盘。
  - 剪辑列表就是必留段（PRD §12）：列表里的段 100% 进片，AI 再用其它可用段补到目标时长。界面上统一叫「剪辑列表」，不再出现「必留」二字（「必留话题」等内部概念不受影响）。
  - 当前段：浅底 + 焦点框；已在列表的段：左侧主色竖条 +「已在剪辑列表」标签。两种状态可叠加。
  - 右侧「剪辑列表」面板（播放器下方）：段数、合计时长 / 目标时长、进度条；按加入顺序列出，每条可点跳转、可 ✕ 移出；合计超过目标时长时变成警告：「已超出目标 0:40，进片时全部保留，建议把目标改为 3:40」（FR-7）。
  - 按 S 后给即时反馈：行内标签出现 + 面板计数跳动；Z 或 ⌘Z 撤销上一次放入 / 移出。
  - 列表变化会让 ⑤ 看结果标「需要更新」（不自动重选）。
- **批量选择**（KI-103）：每行左侧勾选框；先勾一行再 Shift+勾另一行，按当前列表的显示顺序连选；筛选条最前有「全选」，只选当前筛选下看得到的段（部分选中时显示半选）。有勾选时列表下方出现操作栏：「已选 N 段」+ 放入剪辑列表 / 移出剪辑列表 / 标为可用 / 标为废片 / 标为不可用 / 取消选择。
  - 一批作为一次操作：整批保存或整批不改（失败时界面回到原样并保留勾选）；规则与单段相同（放入 = 取消不可用；不可用 = 移出列表并从手动分镜表移除对应镜头）。
  - Z 一次撤销整批。切筛选 / 视图 / 项目、操作成功后勾选清空。S / A / D / X 仍只作用于当前段。
- **快捷键**：默认 空格 播放 / 暂停，↑↓ 换段，S 放入 / 移出剪辑列表，A 可用，D 废片，X 不可用，Z 撤销。可在「更多 → 快捷键」里自定义（逐项「按下新键」录制；与已有键冲突时提示并拒绝；可「恢复默认」；记在本机，所有项目通用）。输入框获得焦点时快捷键不生效。
- 下一步：「去定标准 →」（随时可点；这一步不是闸门）。

### ④ 定标准（S3，闸门 A）

自上而下三块，左侧小目录显示每块完成情况：

1. **分析对不对**：摘要 + 话题 / 关键信息 / 说话人三个证据入口；可改话题名、改某段档位。
2. **裁决待定**（FR-5）：「还有 N 段待定」，一次一段：原文 + 依据 + 播放器，A 可用 / D 废片；可「剩下的按 AI 建议」一次处理完。
3. **决策问题**（FR-6）：3–5 题，每个选项下一行「选了会怎样」；「重新出题」；兜底模板出的题标明。

闸门按钮：「确认，生成分镜表」——保存答案并重新选段，完成后进入 ⑤。待定没裁完时按钮仍可点，但先问「还有 N 段待定，按 AI 建议处理？」。

### ⑤ 看结果（S4，闸门 B）

- **顶栏摘要**：目标时长 3:00（改）· 当前 2:58 · 镜头 18 · 剪辑列表 6/6 进片 ✓。改时长就地弹分 + 秒输入，确定后重新选段。剪辑列表超目标时长时这里变成警告条并直接给建议时长（FR-7）。
- **左：分镜表**（FR-7）：镜号、时间码、字幕（可直接改）、为什么选它（小字）、展开看被删的替代句；↑↓、✕、＋空镜、按时间排序；选中一行可在播放器里设入点 / 出点。
- **右上：预览片**（FR-8）：分镜表改过后显示「分镜表改过了 · 重新生成预览片」。预览片不产生版本号。
- **右下：未采用清单**（FR-8）：可用但没进片的段 + 原因（因时长 / 因重复 / 未勾选为必须记住的信息）；每行「试听」「加回」。加回 = 按时间插入分镜表（算一次手动修改）。
- **工具栏**：「恢复为 AI 选段」（只在手动改过后出现；先确认）。
- **手动修改与重新选段冲突**（改时长、④ 重新确认、③ 改标记导致需要重选时）弹窗：
  > 你手动改过分镜表（N 处）。按新的设置重新选段会覆盖这些修改。
  > 「覆盖，用新的 AI 选段」「保留我的修改」（只更新未采用清单和建议）「取消」
- 闸门按钮：「看过了，去导出 →」——当前分镜表的预览片已生成才可点。

### ⑥ 导出（S5）

- **本次导出**：「导出到 Mac 剪映」（剪映开着时先提示关掉剪映）、「生成 Windows 剪映包」（完成后「在访达中显示」+ 一行用法：拷到 Windows 解压，双击 INSTALL.bat）。每次导出生成新版本 vN（FR-10），剪映里草稿名「片名_vN」。
- **历史版本**：每版一张卡片：版本号、时间、时长、镜头数、预览片播放、「Mac 剪映草稿名」「Windows 包」。
  - 「对比」：选两版并排播放 + 镜头差异（新增 / 删除 / 改字幕）。
  - 「回到这一版」：把该版分镜表恢复到 ⑤（会覆盖当前分镜表，先确认）；不删除任何版本。

## 四、数据外发告知与 Key（首次打开）

首次打开先全屏告知两条外发数据流（音轨 → 火山引擎转写；转写文字 → DeepSeek），「我知道了，继续」后直接进入「填 Key」两行；都填好才进欢迎页。之后在「更多 → 设置 · API Key」改。

## 五、统一名词

| 用这个 | 指什么 | 不再用 |
|---|---|---|
| 素材 | 原始视频 | 原片（对用户） |
| 浏览小样 | 540p 分析代理片，只用于看素材 | 预览（指代理片时） |
| 片段 | 一句话及其三路特征（内容单元） | 段落、镜头（指片段时） |
| 废片 / 待定 / 可用 | 片段档位 | 待判断、L1/L2/L3 |
| 画面提示 | 过暗 / 抖动 / 虚焦 / 静止 等技术标记 | 「废片」tab |
| 剪辑列表 | 剪辑师在 ③ 用 S 挑进来的片段（即 PRD 的必留段），100% 进片 | 必留、★ 必留 |
| 不可用 | ⊘ 标记的片段，永不进片 | — |
| 分镜表 | 当前要出片的镜头列表（AI 选段或手动改过） | 选段表 |
| 预览片 | 按分镜表渲染、带字幕、无 BGM 的视频 | 成片、只出预览 |
| 版本 vN | 每次导出的一份快照 | 成片、第一版、已出片 |
| 剪映工程（Mac / Windows 包） | 导出物 | 剪映草稿、Windows 剪映包混用 |

## 六、旧入口的去向

| 旧 | 新 |
|---|---|
| ① 处理素材 / 开始处理（×3） | ② 分析（新建后自动开始；失败重试在 ② 页） |
| ② 生成成片 / 生成成片 / 生成第一版 | ⑤「重新生成预览片」+ ⑥「导出」 |
| 只出预览（勾选） | 去掉：预览与导出已分开 |
| 确认与提问（独立窗口） | ④ 定标准 |
| 浏览素材（独立窗口）、文稿 tab、废片 tab | ③ 看素材 |
| 剪辑偏好（独立窗口） | ① 新建项目 + 更多 → 项目设置 |
| 改目标时长 | ⑤ 顶栏「改」 |
| 预览 tab（代理片 + 设入出点） | ③ 播放器 + ⑤ 分镜表选中行设入出点 |
| 版本 tab | ⑥ 导出 |
| 打开剪映 | ⑥ 导出后「打开剪映」（仅 Mac） |
| 打开文件夹、清理缓存、设置、诊断包、关于 | 更多菜单 |

## 七、评审已定（2026-10-20）

1. 新建项目「创建并开始分析」一步到位，不再停一下。
2. ④ 待定没裁完时点「确认，生成分镜表」：先问「还有 N 段待定，按 AI 建议处理？」，不拦住。
3. ⑤ 预览片手动点「生成预览片」，进入 ⑤ 时不自动生成。
