# 产品设计：AI 粗剪工作流（五步 + 两道确认）

> 目标：把"AI 猜错了"变成"AI 说清楚，人来定"。
> 原则：**每次 AI 做判断，都必须给依据、给修改入口；每次人要决策，都必须能看到"不选它会怎样"。**
> 本文是 2026-10-18 的设计稿。术语以 [PRD §12](PRD-AI粗剪工具.md#12-附录术语) 为准（档位 = 废片 / 待定 / 可用；「必留段」「必留话题」「指定原话」是三件不同的事）；人工时间预算以 PRD §3.3 为准；与 PRD 冲突处以 PRD 为准。

---

## 一、五步流程（在你给的基础上补了 3 个环节）

```
S0 导入素材
   ↓
S1 abc 综合分析（声音 / 文字 / 画面）        ← 后台跑，可离开
   ↓
S2 分析结果：内容摘要 + 片段浏览器           ← 新增：切片浏览（时间线 / 分类 两种视图）
   ↓
S3 确认与提问：分析对不对 + 3~5 个决策问题    ← 新增：答案直接驱动选段
   ↓
S4 选段 → 预览片（可改、可对比、可回退）
   ↓
S5 导出剪映工程 → 精剪
```

补充的三个环节：

1. **S2 的片段浏览器**（你提的）——我做成了两种视图，并加了三个东西：Level 的**理由**、横向**密度条**、以及"这段在成片里用没用"的标记。
2. **S3 的问题要"可影响结果"**——不是问卷，每个选项都对应一条选段规则（见 §3）。
3. **S4 的"未采用清单"**——预览生成后，单独列出"档位为可用却没进片的片段"。这是防止"重要对话被删"的最后一道保险。

## 二、S2 片段浏览器（详细设计）

### 2.1 时间线视图（默认）

一行一个片段，按时间顺序：

| 字段 | 说明 |
|---|---|
| 时间码 | `07:22–07:56`，点击可跳到原素材该处 |
| 分类 | 逻辑归属（AI 按素材生成，以下为示例）：接待 / 参观 / 讲合同 / 费用 / 就业 / 考证 / 食宿 / 签约 / 学员故事 |
| Level | **废片 / 待定 / 可用**（三档处置状态，**必须给理由**） |
| 摘要 | 这段"在干什么"，一句话，≤20 字 |
| 时长 | 秒 |
| 播放 | 从入点播到出点（播原素材，不生成真切片），自动在出点暂停 |
| 状态 | 已成片用过 / 未用；可标必留段（★） |

**我加的三样：**

- **Level 必须带理由**，例如"可用：含「九千八」「退费」两个关键信息"、"废片：等待镜头，无人物无信息"。只说等级不说理由，人没法反驳。
- **顶部密度条**：一条横跨全片的时间轴，可用=绿、待定=琥珀、废片=深灰。一眼看出"信息集中在哪、哪段整段是空的"。
- **"成片用过没有"**：直接暴露上一版的取舍，避免她看完整片才发现某段被跳过。

### 2.2 分类视图

左侧分类树，右侧该分类的片段：

```
接待与寒暄   可用 2 · 待定 5 · 废片 6    可用时长 18 秒 · 建议 20 秒
讲合同       可用 3 · 待定 1 · 废片 0    可用时长 42 秒 · 建议 45 秒   ← 必留话题
课程与费用   可用 4 · 待定 2 · 废片 0    可用时长 30 秒 · 建议 30 秒   ← 必留话题
就业承诺     可用 5 · 待定 1 · 废片 0    可用时长 40 秒 · 建议 40 秒   ← 必留话题
...
```

**每个分类带"素材时长 / 建议用多少"**——这是上一版翻车的直接原因（必留话题只用了 3.6%），所以必须显式呈现，让她一眼看出配比不合理。

### 2.3 交互细节（小但影响体验）

- 播放时**前后各留 0.3 秒呼吸**，否则每次试听都像被掐断。
- 键盘：`空格` 播放/暂停、`←/→` 前后 5 秒、`A` 标可用、`D` 标废片、`S` 标必留段。
- **"待定"是三档里最值钱的一档**：它是 AI 在说"我拿不准"。界面默认给它一个队列（上限约 40 段/60 分钟，PRD FR-5），
  她按 `A`/`D` 过一遍，≤ 2 分钟清空——**这就是她的判断真正被用上的地方**。
- 任何一次 Level 修改、分类修改都**立即保存**，不需要点"下一步"。
- 快捷筛选：全部 / 待判断 / 可用 / 废片 / 未用（同 PRD FR-4）；必留段在列表里以 ★ 显示。

---

### 2.4 三档 Level 怎么用（不是排序，是处置）

| 档位 | 判定 | 流程里怎么处理 |
|---|---|---|
| **废片** | 无信息、重复、技术废（抖动/失焦/空镜/寒暄） | **不进候选**，只在密度条上留痕，可随时翻出来救回 |
| **待定** | AI 拿不准（主体是人、信息混杂、ASR 置信度低、可能只是 b-roll） | **推给她判断**：默认排成队列，`A` 标可用 / `D` 标废片，≤ 2 分钟清空 |
| **可用** | 有明确信息或画面价值 | 进入选段池，参与"话题覆盖"选择 |

关键点：**"待定"不是低分，而是"需要人"**。三档里只有这一档会占用她的时间，
所以要控制数量（≤ 40 段/60 分钟，PRD FR-5），否则她会被淹没。

《九月一号》实测分布：**废片 46 · 待定 41 · 可用 53**（共 140 段）。
她只需要处理那 41 段——按 `A`/`D` 两个键过一遍，约 1–2 分钟。（当时规则的实测；现由待定上限约束，超出部分按 PRD FR-5 处理）

## 三、S3 确认与提问（问题要能改变结果）

### 3.1 先确认分析

界面上方一句话总结 + 三个可点开的证据链：

```
素材讲了什么：一位母亲带女儿到美业学校报名，看合同、比课程、交九千八。
依据：14 个话题 · 37 处关键信息 · 3 位主要说话人 · 签约发生在 38:00–41:00
       [看话题] [看关键信息] [看说话人]
```

她只需要做一件事：**确认 / 局部修正**（改分类、改 Level、加"不可用"标记）。

### 3.2 再提问（3–5 个，每个都绑定规则）

问题不是固定模板，而是从分析结果里挑"**答案会改变剪法**"的分歧点。每个问题都是单选/多选，带"其他"。

| 问题（由内容生成） | 选项 | 选择后发生什么 |
|---|---|---|
| 这条片子主角是谁？ | 妈妈 / 女儿 / 老师 / 群像 | 决定镜头分配与旁白视角；主角镜头占比 ≥ 40% |
| 必须让观众记住哪些信息？（多选） | 学费九千八 / 退费条款 / 就业承诺 / 年龄限制 / 宿舍条件 | 勾选项对应话题的待定 / 可用片段强制进候选 |
| 结尾落在哪个动作？ | 签字 / 转账 / 走出门 / 老师那句话 | 决定最后 15 秒的取段 |
| 能接受多长的沉默/空镜？ | 几乎不要 / 3 秒以内 / 可以留白 | 决定 b-roll 配额与节奏下限 |
| 有没有不能出现的？ | 未成年正脸 / 机构全称 / 价格 / 无 | 直接标记"不可用"，不进入候选 |

**关键：每个问题下面都要写"选了会怎样"**（一行小字）。否则她不知道这些问题的意义，会随便点。

## 四、S4 预览与"未采用清单"

- 预览片按选段表渲染，带字幕，**只保留同期声、不加 BGM**——这一步的产物是"粗剪工程"，不是成片，加了 BGM 反而会误导她对节奏的判断；

- 右侧同时给出**未采用清单**：档位为可用但没进片的片段，标出"因时长/因重复/因未勾选为必须记住的信息"，她可以一键"加回来"重排（一键加回尚未实现）；
- 每版生成 `v1 / v2 / v3`，可并排对比；
- 她觉得可以了，才走 S5 导出剪映工程。

## 五、数据模型（给开发用）

```
Segment {
  id, start, end, duration,
  category,          // 逻辑分类
  level: 1|2|3,      // 1 废片 · 2 待定 · 3 可用（PRD §12）
  level_reason,      // 必填，人话
  summary,           // "在干什么"，≤20 字
  text, speaker,
  signals: { energy, speech_rate, overlap, has_laugh, ocr_text, props[] },  // ocr_text、props[]：P2（PRD FR-2）
  must_keep: bool,   // 必留段：人标的（PRD §12）
  usable: bool,      // 隐私/授权
  used_in: [v1, v2]  // 哪几版用过
}

Category { id, name, segments[], material_duration, budget_duration }

Review  { analysis_confirmed, answers{question_id: option}, overrides[] }
```

## 六、我给流程加的另外三件事

1. **断点续做**：分析要跑几分钟，允许关页面；回来从上次状态继续（状态存在项目里）。
2. **"不可用"是一等公民**：隐私/未授权片段，不只是"删掉"，而是标记后**永不进入候选**，避免每版都要重新判断。
3. **时间预算**：整个流程她的操作时间控制在 **≤ 20 分钟**（分配见 PRD §3.3）。超过这个数，工具就会被绕过。

## 七、已定事项（2026-10-18）

1. **Level 三档**：废片 / 待定 / 可用 —— 由我们定，不交给剪辑师定义，她只做"待定"的裁决。
2. **分类名**：不固定，由 AI 按素材生成、可在确认页改；以下为《九月一号》生成结果示例（接待与寒暄 / 参观教室 / 讲合同 / 课程与费用 / 就业承诺 /
   考证与政策 / 食宿与安全 / 上课与作息 / 皮肤与闲聊 / 合同答疑 / 签约与付款 / 学员故事）。
3. **预览片不带 BGM**：只保留同期声。目标是粗剪工程，不是成片。
