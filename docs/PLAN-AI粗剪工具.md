## 0. 技术栈（已定）

完整清单见 **[TECH-STACK.md](TECH-STACK.md)**，关键约束三条：

- Python **3.11–3.12**，用 **uv** 隔离（`uv sync` 即得 3.12 环境，`uv.lock` 锁死 48 个包）；标准库 `http.server` + 原生 JS，不引框架；
- 媒体处理用 **ffmpeg 静态二进制**，剪映草稿用 **pyJianYingDraft**，桌面壳用 **pywebview**；
- 外部只依赖两个服务：**MediaKit（ASR/理解）+ DeepSeek API（LLM）**，Key 存 Keychain。

代码根目录：`/Users/developer/Documents/deepseek-harness/default-workspace`（已 `git init`，`projects/`、`dist/` 不入库）。

## 0.1 一句话

**先验证外部依赖（Windows 草稿），再做"分析→浏览→确认→选段"这条主链，最后做导出与打包。**
界面和内核并行推进，避免"UI 等数据"。

## 6. 明确延后（不做）

| 项 | 原因 |
|---|---|
| 自动更新 | 一期手动覆盖足够；P2 再评估 |
| 多素材/多机位 | 当前假设单文件，复杂度高 |
| 自动配 BGM / 卡点 | 属于精剪，不在产品边界 |
| 平台适配建议（标题/封面/发布时间） | 独立模块，等主链稳定 |
| 本地 whisper 离线 | 可联网前提已确认；按需再评估 |
| Windows 代码签名 | 个人使用，SmartScreen 提示可接受 |

## 7. 需要外部配合的两件事

1. **剪辑师测 Windows 导入包**（10 分钟）——决定 M4 的 Windows 分支。
2. **一次 30 分钟访谈**——确认三件事：
   - 她嘴里的分类词是什么（接待 / 谈单 / 签约？）
   - "必留"是否需要整组批量标记
   - 上一版她认为最可惜的 3 句原话（用来校准评分权重）

## 8. 完成定义（DoD）

每个里程碑必须同时满足：

- 功能按 PRD 验收项跑通；
- 有可复现的测试素材与结果记录；
- 失败路径有提示且不产生半成品；
- 剪辑师能在不看文档的情况下完成该阶段操作。

## 9. 如果只做三件事（最小可交付）

按"能不能立刻止血"排序：

1. **M0**（Windows 验证）——0.5 天，决定外部依赖生死。
2. **M2.1 + M2.2**（片段浏览器 + 待定队列）——2.5 天，让剪辑师第一次能"在切之前看到素材"。
3. **M3.1**（覆盖式选段）——2 天，把"必留内容进片率"从不可控变成 100%。

这三件做完，就能用同一条素材给剪辑师一版"能对比"的结果，再决定后面投多少。
